## Core paper explanation

RT-1 turns a short observation history and a language instruction into discrete robot-action predictions. A language-conditioned image encoder produces visual features, a learned token compressor reduces their count, and a transformer predicts action categories. The paper emphasizes control-time efficiency as well as learning across many tasks. Tokenization is especially useful as a standalone component because its ranges, bin boundaries, and reconstruction error can be tested without a robot.

## Execution flow

The inference path compresses language-conditioned visual observations, predicts action bins, and decodes them into the robot’s declared action interface. Training supplies the corresponding discrete action targets.

### Compress visual observations

Let image features be $F\in\mathbb R^{L\times d}$ for $L$ spatial locations and feature width $d$. A useful representation of learned spatial token aggregation is

$$
z_k=\sum_{i=1}^{L}a_{ki}F_i,\qquad a_{ki}\ge0,\quad\sum_i a_{ki}=1.
$$

The learned maps $a_{ki}$ select information for compressed token $k$. This describes the weighted-aggregation mechanism, not every internal layer of the encoder. Language conditioning changes visual features before policy prediction; it should not be confused with applying a text label after an unconditional image model.

### Predict action categories

For target action bin $q_{t,j}$ in channel $j$ at control time $t$, categorical supervision has the form

$$
\mathcal L_{\mathrm{act}}=-\sum_{t,j}\log p_\theta(q_{t,j}\mid O_{\le t},c),
$$

where $c$ is the instruction and the actual transformer masking/token layout determines the permitted context. This compact expression does not impose an additional autoregressive ordering among action channels. The original action interface includes arm, mobile-base, gripper, and mode variables; categorical mode labels must retain their semantics rather than be treated as continuous distances.

### Decode bounded actions

For continuous channel $j$ bounded by $[l_j,u_j]$ and $K$ uniform bins, a teaching codec is

$$
q_j=\operatorname{clip}\left(\left\lfloor K\frac{a_j-l_j}{u_j-l_j}\right\rfloor,0,K-1\right),
\qquad \hat a_j=l_j+\left(q_j+\tfrac12\right)\frac{u_j-l_j}{K}.
$$

The original RT-1 discretizes continuous channels into256uniform bins. [Quantize and Decode Robot Actions](/problems/rt1-action-codec) generalizes the bin count under its explicit contract. For values inside the range, center decoding gives maximum quantization error $(u_j-l_j)/(2K)$. That error is expressed in the channel’s original units; it is not a robot-wide spatial error bound.

## Why this matters on a robot

Token compression can reduce inference work, while discretization makes action prediction categorical. Both introduce information bottlenecks: a visually important contact region may disappear in compression, and coarse action bins may prevent precise movement. Record camera preprocessing, action bounds, controller frames, and inference deadlines together.

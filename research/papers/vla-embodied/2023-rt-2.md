## Core paper explanation

RT-2 adapts pretrained vision-language models into vision-language-action models by expressing robot actions in the model’s output-token space. Training mixes robot demonstrations with vision-language examples so visual and semantic knowledge can influence control predictions. The important interface is the action vocabulary: the text tokenizer, ordered action fields, and physical decoder must agree exactly.

## Execution flow

Images and instructions condition a VLM, robot action categories are emitted in a defined order, and a parser decodes only valid action outputs. Co-fine-tuning mixes robot and vision-language data before deployment.

### Represent actions as tokens

For a continuous action channel with bounds $[l,u]$, a uniform quantizer maps to $q\in\{0,\ldots,K-1\}$. A tokenizer-specific map $v$ then assigns a model token:

$$
\tau=v(q),\qquad q=v^{-1}(\tau).
$$

The map must be one-to-one over the action vocabulary. RT-2’s model variants use different existing-token assignments: conveniently tokenized integers in one case and repurposed rarely used tokens in another. A blanket rule that adds a new vocabulary offset is not universally correct. [Quantize and Decode Robot Actions](/problems/rt1-action-codec) covers the numeric codec prerequisite, not the full RT-2 tokenizer interface.

### Co-fine-tune the model

A transparent description of mixed training is

$$
\mathcal L=\rho\,\mathbb E_{x\sim D_{\mathrm{robot}}}\mathcal L_{\mathrm{AR}}(x)
+(1-\rho)\,\mathbb E_{x\sim D_{\mathrm{VLM}}}\mathcal L_{\mathrm{AR}}(x),
\quad0\le\rho\le1,
$$

where $\mathcal L_{\mathrm{AR}}=-\sum_i\log p_\theta(y_i\mid I,c,y_{<i})$. The mixture coefficient describes a sampling/loss policy; exact experimental choices must match the paper configuration being reproduced. Robot examples supervise ordered action fields, while other examples supervise their own text targets.

### Parse and execute actions

Let $\mathcal G$ be the set of legal serialized action sequences. A parser accepts an output only when

$$
\tau\in\mathcal G,\qquad v^{-1}(\tau_j)\in\{0,\ldots,K-1\}
$$

for every continuous field, with separate rules for termination and discrete modes. This grammar check is an engineering safeguard, not a claim that grammatical outputs are safe actions. Reconstruct each field using its declared bounds, frame, and control period. Reject a missing channel rather than shifting subsequent values into the wrong actuator field.

## Why this matters on a robot

A pretrained VLM may improve semantic generalization, yet token validity and fluent reasoning do not guarantee collision-free control. Action range changes, token remapping, and long inference delays can invalidate an otherwise well-trained checkpoint. Version the tokenizer and action decoder together.

## Agent brief

Use CLIP to teach normalized multimodal embeddings, in-batch negatives, a learnable temperature, zero-shot classifiers built from prompts, and retrieval evaluation. Keep data-governance issues visible alongside the algorithm.

## Contribution

CLIP jointly trains an image encoder and text encoder to identify matched image-caption pairs among a batch. The shared embedding space supports zero-shot recognition by comparing image features with prompted class-text features.

## Prerequisite concepts

- Image and text encoders
- Cosine similarity, L2 normalization, and softmax temperature
- Cross-entropy with in-batch negatives
- Retrieval metrics and prompt ensembling

## Method map

1. Encode a batch of images and their paired texts independently.
2. Normalize both feature sets and form the full pairwise similarity matrix.
3. Scale similarities by a learned logit temperature.
4. Average image-to-text and text-to-image cross-entropy losses.
5. At inference, encode class prompts and use their similarities as zero-shot logits.

## Essential equations

With unit-normalized image and text features, pairwise logits are

$$
s_{ij}=e^{\tau}\,\frac{v_i^{\mathsf T}t_j}{\lVert v_i\rVert_2\lVert t_j\rVert_2},
$$

where (\tau) is a learned log-scale. For aligned pairs in a batch, the symmetric objective is

$$
\mathcal L=\tfrac12\left[
\operatorname{CE}_{\mathrm{row}}(S,I)+
\operatorname{CE}_{\mathrm{col}}(S,I)
\right],
$$

with the diagonal as the positive-pair target.

## Visual teaching plan

- **Similarity matrix:** A live heatmap shows diagonal positives and in-batch negatives while temperature changes the distribution sharpness.
- **Embedding plane:** Project a toy image/text batch into 2D and animate paired embeddings moving together during optimization.
- **Prompt ensemble:** Edit prompt templates and watch class prototypes, zero-shot logits, and calibration shift for the same image.

## Data and evaluation

The paper trains on a large web-derived image-text corpus and evaluates zero-shot transfer and linear probes across many vision datasets. A teaching version can use a licensed small dataset, reporting symmetric retrieval recall@K, zero-shot accuracy, calibration, and prompt sensitivity.

## Limitations and failure modes

- Web-scale data can encode harmful social, geographic, and cultural biases.
- Zero-shot behavior is sensitive to class wording and prompt templates.
- Global contrastive features can miss spatial relationships and fine-grained localization.
- Batch composition and distributed all-gather semantics materially change the negative set.

## Implementation decomposition

1. Feature normalization and pairwise logits.
2. Symmetric contrastive loss with temperature clamping.
3. Distributed feature gathering while preserving local gradients.
4. Prompt template encoding and class prototype averaging.
5. Retrieval, zero-shot, calibration, and bias-slice evaluation.

## Problem blueprints

### Symmetric CLIP loss

- **Type:** PyTorch loss implementation
- **Difficulty:** Medium
- **Inputs:** Image embeddings, text embeddings, log-temperature parameter
- **Outputs:** Scalar symmetric loss and both accuracy directions
- **Grading:** Normalization; diagonal labels; bidirectional average; stable temperature; numerical and gradient match

### Build a zero-shot classifier

- **Type:** Embedding/prompt pipeline
- **Difficulty:** Medium
- **Inputs:** Text encoder, class names, prompt templates, image embeddings
- **Outputs:** Class prototypes, logits, and predicted IDs
- **Grading:** Template batching; normalized mean prototypes; deterministic class order; correct temperature application

### Compute bidirectional retrieval metrics

- **Type:** Evaluation
- **Difficulty:** Medium
- **Inputs:** Image/text embeddings and one-to-many relevance IDs
- **Outputs:** Image-to-text and text-to-image recall@K plus median rank
- **Grading:** Multiple positives; stable ties; chunked similarity option; exact reference values

## MLOps and deployment extensions

- Version tokenizer, prompt templates, preprocessing, and label vocabulary with the encoders.
- Track retrieval and zero-shot metrics by domain, language, geography, and safety-relevant slices.
- Cache text prototypes with encoder/checkpoint hashes and invalidate them on prompt or tokenizer changes.
- Benchmark image and text paths independently; use embedding-drift dashboards after deployment.

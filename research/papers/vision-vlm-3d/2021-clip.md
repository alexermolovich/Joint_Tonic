## Core paper explanation

CLIP learns an image encoder and a text encoder by asking which caption matches each image in a batch. It maps both modalities into a shared space where paired examples should have larger similarity than mismatched examples. Once learned, that space supports image-text retrieval and classifiers made from text descriptions. The essential mechanism is the two-direction contrastive objective; the semantics available at deployment also depend strongly on the training data and prompt wording.

## Execution flow

Images and text are encoded and normalized, then compared in a pairwise matrix. Training uses known pairs; inference replaces paired captions with candidate descriptions or a retrieval collection.

### Encode and normalize

Let $V,T\in\mathbb R^{N\times d}$ contain a batch of $N$ paired image and text embeddings, each with feature width $d$. Normalize each row:

$$
\bar v_i=\frac{v_i}{\|v_i\|_2},\qquad
\bar t_i=\frac{t_i}{\|t_i\|_2}.
$$

The dot product of normalized rows is cosine similarity. Embedding components have no physical length units and are not 3D coordinates. Zero-norm vectors need an explicit numerical policy in a software contract. Image resizing, channel normalization, and text tokenization are part of the model, even when the encoder API hides them.


**Implement this component:** [Normalize Image and Text Embeddings](/problems/clip-normalize-embeddings). Each linked exercise implements its stated bounded subcomponent; completing it is not a full-paper reproduction.

### Train on paired similarities

For temperature $\tau>0$, define $S_{ij}=\bar v_i^\top\bar t_j/\tau$, giving $S\in\mathbb R^{N\times N}$. The paper learns a logit scale, which can be written $s=\exp(\gamma)=1/\tau$. Averaging the two retrieval losses gives

$$
\mathcal L=-\frac{1}{2N}\sum_{i=1}^{N}
\left[\log\frac{e^{S_{ii}}}{\sum_j e^{S_{ij}}}
+\log\frac{e^{S_{ii}}}{\sum_j e^{S_{ji}}}\right].
$$

Rows classify the matching text for an image; columns classify the matching image for a text. A small $\tau$ sharpens both distributions. [Compute Symmetric CLIP Contrastive Loss](/problems/clip-symmetric-loss) implements this component with its documented temperature and validation contract. Use log-sum-exp for numerical stability; assuming that matching labels are diagonal is correct only when the batch pairing order is preserved.


**Implement this component:** [Compute Symmetric CLIP Contrastive Loss](/problems/clip-symmetric-loss). Each linked exercise implements its stated bounded subcomponent; completing it is not a full-paper reproduction.

### Retrieve or classify

For class $c$ and prompt templates $p$, a normalized prototype can be formed as

$$
w_c=\operatorname{normalize}\left(\frac{1}{P}\sum_{p=1}^{P}
\operatorname{normalize}(f_T(\mathrm{prompt}_p(c)))\right),
\qquad \hat c=\arg\max_c\bar v^\top w_c.
$$

The normalization after averaging matters: otherwise prototype length changes the score. In retrieval, replace class prototypes with individual text or image embeddings. A large similarity is evidence of embedding compatibility, not a calibrated guarantee that a robot can safely execute a described action.

#### Separate prompt changes from class-frequency changes

[Prompt and class drift](/problems/clip-prompt-class-drift) is an original monitoring extension. For corresponding old/new normalized text prototypes $a_c,b_c\in\mathbb R^D$, cosine distance is $d_c=1-a_c^\top b_c$. For old/new class proportions $p,q\in\mathbb R^C$ and $m=(p+q)/2$,
$$\operatorname{JS}(p,q)=\tfrac12\operatorname{KL}(p\|m)+\tfrac12\operatorname{KL}(q\|m).$$
All scores are dimensionless; natural-log JS ranges from zero to $\log2$, with zero-mass terms contributing zero. Positive prototype scaling and equal proportional count scaling do not change these diagnostics. Keep class order and encoder identity fixed. These are monitoring signals, not CLIP training losses or proof of degraded robot-task performance.

## Why this matters on a robot

Language-conditioned perception can reuse text descriptions instead of training a separate classifier for every object category. Global image-text alignment can still miss spatial relations, counts, and fine-grained manipulations. Background shortcuts and prompt sensitivity are especially important when a robot must distinguish a handle from the surrounding object. Evaluate retrieval and task-specific grounding separately.

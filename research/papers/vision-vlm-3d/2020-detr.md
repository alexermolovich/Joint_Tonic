## Core paper explanation

DETR treats detection as predicting a set of objects rather than assigning a label to every anchor. A transformer decoder receives learned object queries and emits a fixed-size set of class and box predictions. During training, bipartite matching assigns each ground-truth object to one prediction; unmatched predictions learn the no-object label. This removes the need for hand-designed anchor matching and duplicate-suppression rules in the original detection pipeline.

## Execution flow

An image becomes spatial tokens, object queries decode a prediction set, and a training-only one-to-one assignment determines supervision. Inference reads object predictions directly; matching is not run against unavailable ground truth.

### Encode spatial features

A convolutional backbone produces $F\in\mathbb R^{h\times w\times d}$. Flattening gives $hw$ spatial tokens; positional information distinguishes otherwise identical feature vectors at different locations. Scaled dot-product attention uses

$$
\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.
$$

Here $d_k$ is key/query feature width. Attention weights sum to one over allowed keys; padding masks must remove tokens from padded image regions.

### Decode object queries

For $N$ learned object queries, the decoder emits class probabilities $\hat p_i$ and boxes $\hat b_i\in[0,1]^4$. Boxes use normalized center and size $(c_x,c_y,w,h)$. A box head and a classification head share the query representation. The model may emit fewer than $N$ real objects because a separate no-object category absorbs unused slots.

$$
(\hat p_i,\hat b_i)=\bigl(\operatorname{softmax}(W_c z_i),\ \operatorname{sigmoid}(\operatorname{MLP}_b(z_i))\bigr).
$$

Normalized box coordinates must be converted through the actual image resize/padding transform before use with camera geometry.




**Planned components:** Decode Normalized Boxes and Classes from Object Queries. These remain unreviewed ideas without runnable exercises.

### Match and train the set

Let $M\le N$ targets be $(c_j,b_j)$. Find an injective assignment

$$
\hat\sigma=\arg\min_\sigma\sum_{j=1}^{M}
\left[-\hat p_{\sigma(j)}(c_j)
+\lambda_1\|b_j-\hat b_{\sigma(j)}\|_1
+\lambda_g\bigl(1-\operatorname{GIoU}(b_j,\hat b_{\sigma(j)})\bigr)\right].
$$

The matching classification cost uses class probability; the training classification loss uses negative log probability. These are related but not identical objectives. Generalized IoU adds a penalty for empty space in the smallest enclosing box, supplying a signal even when boxes do not overlap. [Pairwise IoU](/problems/box-iou-broadcast) is a useful prerequisite, but it does not implement GIoU or Hungarian assignment. Unmatched queries receive weighted no-object supervision.

#### Train the assignment and inspect missed objects

[Matched DETR losses](/problems/detr-matched-training-losses) makes the classification/geometry reductions explicit. For query labels $y_q$ (including no-object) and weights $w_q$ equal to a supplied background weight for no-object and one otherwise,
$$L_{\mathrm{class}}=\frac{\sum_q w_q[-\log\operatorname{softmax}(z_q)_{y_q}]}{\sum_qw_q}.$$
Here $z_q\in\mathbb R^{C+1}$ are dimensionless class logits. Paired center-size L1 and $(1-\operatorname{GIoU})$ terms are normalized by the number of real targets, using zero geometric loss when that count is zero. The exercise is single-image and omits auxiliary decoder/distributed losses.

[Query and small-object diagnostics](/problems/detr-query-small-object-diagnostics) reports high-cosine query pairs and small targets lacking an IoU-qualified prediction separately. This original diagnostic is class-agnostic and does not prove query collapse; large embedding similarity and missing geometry are evidence requiring investigation.

## Why this matters on a robot

A set formulation makes duplicate handling part of learning, but object count, small objects, and occlusion remain difficult. A robot should validate coordinate conversions and class confidence independently of the matching code. Testing only an assignment cost matrix can miss a transposed class dimension or an incorrect background label.

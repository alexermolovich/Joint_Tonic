## Agent brief

Use DETR to turn detection into a set problem. The high-value exercises are matching predictions to ground truth, treating unmatched queries as no-object, and composing classification, L1, and generalized-IoU losses.

## Contribution

DETR replaces anchors and NMS with a fixed set of learned object queries and a global one-to-one assignment. A Transformer encoder-decoder predicts all objects in parallel, while Hungarian matching makes output order irrelevant.

## Prerequisite concepts

- Transformer attention and positional encodings
- Bounding-box coordinate formats and generalized IoU
- Bipartite matching / Hungarian assignment
- Cross-entropy, L1 loss, and padding masks

## Method map

1. Extract a spatial feature map with a convolutional backbone.
2. Flatten the map, add 2D position encodings, and apply a Transformer encoder.
3. Decode a fixed bank of learned object queries against the encoded image.
4. Predict one class distribution (including no-object) and normalized box per query.
5. Match ground-truth objects to queries using a class/box cost, then compute matched losses.

## Essential equations

One-to-one assignment chooses the minimum-cost permutation

$$
\hat\sigma=\arg\min_{\sigma}\sum_{j=1}^{M}
\mathcal C\!\left(y_j,\hat y_{\sigma(j)}\right).
$$

For a matched object, a compact training loss is

$$
\ell_j=-\log \hat p_{\sigma(j)}(c_j)
+\lambda_1\lVert b_j-\hat b_{\sigma(j)}\rVert_1
+\lambda_g\bigl(1-\operatorname{GIoU}(b_j,\hat b_{\sigma(j)})\bigr).
$$

Unmatched queries receive the no-object class target.

## Visual teaching plan

- **Matching matrix:** Render query-target costs as a heatmap; changing cost weights redraws the Hungarian assignment lines.
- **Query lifecycle:** Animate learned queries attending to image regions across decoder layers, without implying each query has a fixed semantic identity.
- **Anchor-free comparison:** Side-by-side flow diagrams contrast anchor generation/NMS with fixed queries/one-to-one matching.

## Data and evaluation

The paper trains and evaluates on COCO, reporting AP across IoU thresholds and object scales, plus panoptic segmentation experiments. A compact implementation can use synthetic boxes or a small COCO subset, but should preserve the matching and metric semantics.

## Limitations and failure modes

- The original system converges slowly and is weaker on small objects than strong multi-scale baselines.
- Fixed query count imposes an upper bound on detections.
- Matching cost weights and no-object weighting are sensitive configuration choices.
- Backbone, image-mask, and position-encoding shape mistakes can silently degrade training.

## Implementation decomposition

1. Box conversion, IoU, and GIoU primitives.
2. Pairwise matching-cost matrix.
3. Hungarian assignment with rectangular and empty-target cases.
4. Matched class/L1/GIoU losses and no-object targets.
5. Query decoder output post-processing and COCO-format conversion.

## Problem blueprints

### Build the DETR matching matrix

- **Type:** Vectorized tensor operation
- **Difficulty:** Medium
- **Inputs:** Query logits/boxes, target labels/boxes, cost weights
- **Outputs:** Pairwise cost matrix per image
- **Grading:** Correct class, L1, and GIoU signs/scales; no query-target loops; rectangular and empty cases

### Hungarian target assignment

- **Type:** Algorithm integration
- **Difficulty:** Hard
- **Inputs:** Per-image cost matrices
- **Outputs:** Matched query and target index arrays
- **Grading:** Globally minimal assignment; deterministic ties; batched variable target counts; indices on the expected device after integration

### Compute matched DETR losses

- **Type:** PyTorch loss implementation
- **Difficulty:** Hard
- **Inputs:** Query predictions, assignments, ground truth, no-object weight
- **Outputs:** Named classification, L1, GIoU, and cardinality metrics
- **Grading:** Reference numerical values; correct normalization across distributed/empty batches; finite backward pass

## MLOps and deployment extensions

- Log assignment statistics, no-object probability, query utilization, and object-count error during training.
- Freeze a post-processing schema for normalized boxes, image resizing, and class IDs across export formats.
- Benchmark encoder, decoder, and backbone latency separately to guide optimization.
- Add small-object and crowded-scene slices to release gates; aggregate AP alone can hide regressions.

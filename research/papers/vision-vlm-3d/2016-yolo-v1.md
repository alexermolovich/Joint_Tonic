## Agent brief

Use this paper to teach the complete mechanics of a real-time detector: assigning objects to spatial cells, encoding boxes, combining localization/objectness/class terms, decoding predictions, and measuring accuracy under a latency budget.

## Contribution

YOLO collapses a multi-stage detection pipeline into one network that predicts boxes and class probabilities over a fixed grid. Its historical value is the unified formulation and explicit speed-versus-localization tradeoff, not that its original architecture remains a modern production default.

## Prerequisite concepts

- Convolutions, tensor shapes, and normalized image coordinates
- Intersection over Union (IoU), confidence scores, and non-maximum suppression
- Mean squared error and classification metrics

## Method map

1. Divide the image into an `S x S` grid; a cell is responsible for an object whose center falls inside it.
2. Predict `B` boxes per cell as center, width, height, and confidence values.
3. Predict conditional class probabilities per cell.
4. Train a weighted loss that separates coordinate, object-confidence, no-object, and class terms.
5. Decode predictions to image coordinates, threshold scores, and suppress duplicates.

## Essential equations

For boxes (a) and (b), overlap quality is

$$
\operatorname{IoU}(a,b)=\frac{|a\cap b|}{|a\cup b|}.
$$

An inference score can be written as objectness times the conditional class probability:

$$
s_{c,k}=\hat o_k\,\hat p(c\mid k),
$$

where (k) indexes a predicted box. The original formulation trains confidence toward an object indicator multiplied by IoU for the responsible predictor.

## Visual teaching plan

- **Grid assignment diagram:** Overlay a draggable `S x S` grid on an image; moving a box center highlights the responsible cell and shows normalized offsets.
- **Decode explorer:** Sliders for center offsets, square-root width/height, objectness, and class probability update the rendered box and final score.
- **NMS animation:** Step through score sorting and suppression while an IoU matrix updates alongside the boxes.

## Data and evaluation

The paper evaluates on PASCAL VOC 2007/2012 and compares mean average precision and throughput with contemporary detectors. A teaching implementation should evaluate box correctness, class correctness, mAP at a stated IoU threshold, and end-to-end latency rather than accuracy alone.

## Limitations and failure modes

- A coarse grid makes nearby or small objects difficult.
- The original loss treats several heterogeneous errors as squared-error terms.
- Fixed box capacity per cell limits crowded scenes.
- Modern YOLO-family systems differ substantially; avoid presenting this card as the specification of current YOLO versions.

## Implementation decomposition

1. Coordinate conversion and IoU utilities.
2. Cell responsibility and target tensor construction.
3. Loss terms with object/no-object masks.
4. Box decoding and confidence composition.
5. NMS, AP computation, and latency measurement.

## Problem blueprints

### Assign targets to grid cells

- **Type:** NumPy tensor construction
- **Difficulty:** Medium
- **Inputs:** Image width/height, grid size, labeled `xyxy` boxes, class IDs
- **Outputs:** Dense grid target containing normalized offsets, square-root width/height targets, object mask, and class target
- **Grading:** Exact shape/order; boundary-center cases; multiple labels in one cell handled according to a stated policy; values within tolerance

### Compute the YOLO v1 masked loss

- **Type:** PyTorch loss implementation
- **Difficulty:** Hard
- **Inputs:** Predicted tensor, target tensor, responsible-box mask, loss weights
- **Outputs:** Total loss and named coordinate/object/no-object/class components
- **Grading:** Numerical match to reference; zero-object batches; gradients finite; no unintended broadcasting

### Decode and suppress detections

- **Type:** Detection post-processing
- **Difficulty:** Medium
- **Inputs:** Grid predictions, score threshold, IoU threshold, image size
- **Outputs:** Sorted `(box, class, score)` detections
- **Grading:** Coordinate reconstruction, class-score multiplication, class-aware NMS, stable tie behavior, empty-input case

## MLOps and deployment extensions

- Export decoding and NMS as a versioned post-processing contract and compare native versus ONNX/TensorRT outputs.
- Track mAP, small-object recall, images/second, P50/P95 latency, and peak memory by model version.
- Add drift slices for illumination, camera angle, object scale, and scene density.
- Validate quantization with both end-to-end mAP and per-head tensor error, not latency alone.

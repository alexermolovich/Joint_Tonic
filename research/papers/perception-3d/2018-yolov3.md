## Core paper explanation

YOLOv3 predicts objects at multiple feature scales using anchor-relative box parameters. Its box representation differs from the original YOLO grid formulation: centers use sigmoid offsets, sizes use exponentials relative to anchors, and class scores use independent logistic predictions. The implementation must preserve which scale, cell, and anchor produced each box.

## Execution flow

Predict anchor-relative values at several resolutions, decode them into image geometry, then score and suppress detections.

### Decode anchor parameters

For cell offset $(c_x,c_y)$ and anchor size $(p_w,p_h)$ in consistent grid units,

$$
b_x=\sigma(t_x)+c_x,\quad b_y=\sigma(t_y)+c_y,
\quad b_w=p_we^{t_w},\quad b_h=p_he^{t_h}.
$$

Convert these values to the image scale with the feature stride. [Decode YOLO Grid Predictions](/problems/decode-yolo-grid) is related practice but has its own explicit contract; do not substitute this anchor/exponential rule into that exercise unless its specification requests it.

### Merge prediction scales

If level $\ell$ has $H_\ell W_\ell$ cells and $A_\ell$ anchors, total candidate count is

$$
N=\sum_\ell H_\ell W_\ell A_\ell.
$$

All candidates must be expressed in the same pixel convention before merging. Swapping anchor and spatial axes can produce valid tensor shapes with incorrect box geometry. Keep batch indices separate from this flattening.


**Planned component problems:** Verify tensor flattening and scale transforms. These are planned work, not runnable links; titles without a reviewed blueprint remain unreviewed ideas.

### Score and suppress detections

For objectness logit $o$ and class logit $z_c$, a class score is

$$
s_c=\sigma(o)\sigma(z_c).
$$

Independent sigmoid class outputs differ from a softmax that forces mutually exclusive categories. [Pairwise IoU](/problems/box-iou-broadcast) and [class-aware NMS](/problems/class-aware-nms) provide the overlap and duplicate-removal components. A score threshold must be selected using the intended evaluation protocol.

## Why this matters on a robot

Anchor sizes, image resizing, and feature stride jointly determine spatial accuracy. Exponential size decoding can overflow for extreme logits, so documented numeric bounds matter. Evaluate small objects and clutter at the camera resolution actually used on the robot.

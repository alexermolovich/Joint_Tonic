## Core paper explanation

AWQ performs activation-aware weight-only quantization. It identifies channels important to layer outputs through activation statistics and rescales weights to reduce quantization error without relying on mixed-precision protection of individual weights.

## Execution flow

Follow the data through the mechanism. Training objectives and inference behavior are distinguished in the linked explanations.

### Inspect activation importance

For a linear layer $Y=XW$, weight error $\Delta W$ produces output error $\Delta Y=X\Delta W$. Large activation channels amplify corresponding weight errors. This explains why weight magnitude alone is not an adequate importance measure.


**Component practice**

- Runnable component: [Compare Activation-Weighted Quantization Error](/problems/awq-activation-weighted-error). Uses the bounded contract; no full paper reproduction is claimed.

### Search equivalent channel scales

For positive diagonal scale $S$,
$$\hat Y=(XS^{-1})Q(SW).$$
Without $Q$, this equals $XW$. AWQ searches scaling choices using calibration activation statistics and output error, with clipping choices in its quantization recipe. It does not require gradient-based model retraining.


**Component practice**

- Runnable component: [Compute Group-Wise Quantization Parameters](/problems/awq-groupwise-quantization). Uses the bounded contract; no full paper reproduction is claimed.

### Serve low-bit weights

A useful layer diagnostic is $\|XW-\hat Y\|_F^2/\|XW\|_F^2$ when the denominator is nonzero. This is a teaching error measure, not a substitute for task evaluation. Weight-only compression leaves activation precision and runtime kernels as separate design choices.

## Why this matters on a robot

Weight-only quantization can reduce VLM memory pressure. Calibration drift, unsupported kernels, and small but consequential action-output changes require deployment-specific checks.

## Scope of the runnable components

[Activation-weighted comparison](/problems/awq-activation-weighted-error) evaluates the complete calibration output error for supplied quantized candidates, including channel correlations. [Groupwise quantization](/problems/awq-groupwise-quantization) is an explicit affine teaching recipe: contiguous row groups, ranges extended to include zero, ties-to-even rounding of signed values before zero-point addition, and a positive float64 scale floor. It returns unpacked uint8 logical codes and reconstructed weights; it does not implement AWQ's complete scale/clipping search or its packed serving kernels. The linked VLA memory estimate remains a supplied-overhead budget, not a measured AWQ deployment.

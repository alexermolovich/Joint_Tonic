## Core paper explanation

BLIP-2 learns a compact Querying Transformer between frozen image and language models. Learned queries extract a small visual bottleneck, first through image–text representation learning and then through language generation.

## Execution flow

Follow the data through the mechanism. Training objectives and inference behavior are distinguished in the linked explanations.

### Query frozen image features

A frozen encoder produces $V\in\mathbb R^{N\times d_v}$. The Q-Former maps $M$ learned queries to $Z\in\mathbb R^{M\times d_q}$ through self-attention and cross-attention. $M$ is much smaller than the raw feature sequence, limiting what the language model receives.

### Train the query bottleneck

The first stage jointly uses image–text contrastive learning, image–text matching, and image-grounded text generation:
$$L_{\mathrm{stage1}}=L_{\mathrm{ITC}}+L_{\mathrm{ITM}}+L_{\mathrm{ITG}}.$$
For contrastive image–text similarity, the maximum similarity across query outputs selects the query best aligned with the text. Different attention masks control query–text interaction across objectives.


**Planned component problems:** Count Trainable and Frozen Parameters. These are planned work, not runnable links; titles without a reviewed blueprint remain unreviewed ideas.

### Connect the frozen language model

A trainable projection creates visual prefix embeddings $P=ZW$, with $W\in\mathbb R^{d_q\times d_{\mathrm{LM}}}$. The generation stage optimizes
$$L_{\mathrm{stage2}}=-\sum_t\log p_{\mathrm{frozen\ LM}}(y_t\mid y_{<t},P).$$
Gradients update the bridge through the frozen language model. Decoder-only and encoder–decoder language models use different text conditioning layouts; the prefix notation is schematic.

## Why this matters on a robot

A learned bottleneck can reduce the cost of connecting camera features to a language model. It can also discard small but safety-relevant objects; evaluate visual evidence retention instead of trusting fluent answers.

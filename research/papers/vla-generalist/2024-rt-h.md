## Core paper explanation

RT-H introduces a language hierarchy between a task instruction and low-level robot actions. Intermediate language motions, such as moving an arm in a direction, provide reusable structure and an interface for human corrections.

### Predict a language motion

With task $\ell$ and observation $o$, the high-level model predicts $m\sim p_\theta(m\mid o,\ell)$. The intermediate description captures local motion rather than replacing the overall task. Motion annotations are derived from action information using the paper's labeling procedure.

### Condition robot actions

The hierarchy factorizes as
$$p(a,m\mid o,\ell)=p(m\mid o,\ell)\,p(a\mid o,\ell,m).$$
A conceptual supervised objective is
$$L=-\log p(m^*\mid o,\ell)-\log p(a^*\mid o,\ell,m^*).$$
This expresses the two prediction tasks; their implementation uses the paper's shared VLM and prompt formats.

### Correct and resume

A human can supply $m_{\mathrm{human}}$ so the action model conditions on that correction, then return control to automatic motion prediction. Corrections must stay attached to the corresponding observations and actions. A phrase such as “forward” requires an explicit frame in any educational control contract.

## Why this matters on a robot

Intermediate language can make a policy’s immediate intent easier to inspect and correct. It does not remove ambiguity in coordinate frames or ensure that the lower-level action faithfully realizes the requested motion.

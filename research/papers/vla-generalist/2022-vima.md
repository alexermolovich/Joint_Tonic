## Core paper explanation

VIMA learns manipulation from prompts that interleave language and visual examples. Object-centric representations and cross-attention to the prompt support task specifications such as matching an example object or reproducing a demonstrated arrangement.

## Execution flow

### Tokenize objects and prompts

Each detected object contributes visual and geometric features; a prompt becomes a sequence $P\in\mathbb R^{M\times d}$. Current observations become object tokens $O_t\in\mathbb R^{N_t\times d}$. Variable object counts require masks; zero-padding must not create additional apparent objects.

### Condition the policy

A prompt cross-attention operation is
$$H'=\operatorname{softmax}\!\left(\frac{(HW_Q)(PW_K)^\top}{\sqrt{d_k}}\right)PW_V.$$
Causal self-attention models prior observations/actions, while prompt cross-attention supplies task context. VIMA's object-centric input differs from treating the entire image as one embedding.

### Imitate manipulation actions

Behavior cloning optimizes
$$L=-\sum_t\log\pi_\theta(a_t\mid o_{\le t},a_{<t},P).$$

## Why this matters on a robot

Visual examples help specify unfamiliar objects or spatial arrangements. Detection failures occur before policy reasoning, so object recall and prompt-grounding quality should be evaluated separately from action execution.
